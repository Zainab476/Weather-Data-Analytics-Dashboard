# Project Summary
The Weather Data Analytics Dashboard is a comprehensive web application designed to fetch and analyze weather data from the OpenWeatherMap API. It provides insights such as average temperature, hottest and coldest months, rainfall trends, and weather forecasting through interactive charts and visualizations. This project aims to transform a basic React weather app into a powerful data analysis tool, making it suitable for users interested in understanding weather patterns and trends.

# Project Module Description
- **Pages**: Main dashboard page where the application is rendered.
- **Components**: Various UI components for displaying weather data, analytics metrics, and visualizations.
- **Services**: API communication layer for fetching weather data.
- **Types**: TypeScript interfaces defining data structures used throughout the application.

# File Description Inventory
- **App.tsx**: Main application component that renders the dashboard.
- **Index.tsx**: Entry point for the application, rendering the WeatherDashboard component.
- **components/**: Contains all UI components such as CurrentWeather, AnalyticsCards, TemperatureChart, RainfallChart, MonthlyComparison, and ForecastTable.
- **services/weatherApi.ts**: API service for fetching weather data.
- **types/weather.ts**: TypeScript interfaces for weather data structures.
- **index.css**: Global CSS styles using Tailwind CSS.

# Technology Stack
- **React**: Frontend library for building user interfaces.
- **TypeScript**: Superset of JavaScript for type safety.
- **Vite**: Build tool for faster development and bundling.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Recharts**: Charting library for data visualization.
- **Axios**: HTTP client for making API requests.
- **date-fns**: Library for date manipulation.

# Usage
1. **Install dependencies**: Run `pnpm install` in the `app/frontend` directory.
2. **Build the application**: Execute `pnpm run build` to create a production build.
3. **Run the application**: Use `pnpm run dev` to start the development server.

To utilize live weather data, add your OpenWeatherMap API key as the `VITE_OPENWEATHER_API_KEY` environment variable.
